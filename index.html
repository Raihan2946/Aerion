ABOUT SYSTEM

Monitoring Cerdas untuk Lingkungan Mikroalga

Sistem dirancang untuk membantu pemantauan kondisi lingkungan pada proses budidaya mikroalga melalui sensor dan teknologi IoT.

01

Sensor Environment

ENS160 digunakan untuk memperoleh parameter kualitas udara seperti eCO₂, TVOC dan AQI.

02

Monitoring Cahaya

Sensor LDR digunakan untuk membaca kondisi intensitas cahaya lingkungan sebagai bagian dari sistem kontrol.

03

IoT Cloud

Data sensor dikirim melalui koneksi internet dan dapat dipantau melalui dashboard secara real-time.
